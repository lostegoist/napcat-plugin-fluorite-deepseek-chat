# Napcat 插件——Fluorite-deepseek-chat

## 介绍
这是一个基于 Napcat 插件模板的插件，用于 QQ 用户与 DeepSeek 大模型聊天。

### 使用方式
- **群聊**：@ 机器人并输入内容，例如 `@机器人 你好`
- **私聊**：直接发送文字即可
- **管理命令**（默认前缀 `#cmd`）：`#cmd help`、`#cmd ping`、`#cmd status`

### 构建
```bash
pnpm install
pnpm run build
```
将 `dist` 目录部署到 NapCat 插件目录并加载。
